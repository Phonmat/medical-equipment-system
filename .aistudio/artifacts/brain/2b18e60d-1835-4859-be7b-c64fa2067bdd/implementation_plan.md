# ปรับปรุงส่วนปุ่มตั้งค่าวันใช้งานด่วนในการ์ดสถานประกอบการ

นำปุ่มตั้งค่าวันใช้งานด่วน (`30 วัน`, `90 วัน`, `180 วัน`, `365 วัน`) กลับมาแสดงผลในกล่องกำหนดวันใช้งานของการ์ดสถานประกอบการ และลบเฉพาะข้อความกำกับ `"ตั้งค่าด่วน:"` ออกตามที่ระบุ

## User Review & Critical Decisions

> [!IMPORTANT]
> แผนการแก้ไขนี้จะคืนค่าปุ่มลัดกำหนดวันใช้งานทั้ง 4 ปุ่มกลับมาแสดงผลเคียงข้างตัวเลือกวันหมดอายุ โดยตัดเฉพาะข้อความ `"ตั้งค่าด่วน:"` ด้านหน้าปุ่มออกเท่านั้น

- **Confirmed Decision**: แสดงปุ่ม `30 วัน`, `90 วัน`, `180 วัน`, `365 วัน` ตามเดิม โดยไม่มีข้อความ `"ตั้งค่าด่วน:"` นำหน้า

## 1. Overview & Core Concept

- **What It Does**: คืนค่าปุ่มกดตั้งค่าจำนวนวันใช้งานด่วน (`30 วัน`, `90 วัน`, `180 วัน`, `365 วัน`) ในการ์ดสถานประกอบการสำหรับ Super Admin โดยลบเฉพาะป้ายข้อความ `"ตั้งค่าด่วน:"` ออกเพื่อให้ประหยัดพื้นที่ในบรรทัดเดียวกัน
- **Target Audience / Persona**: ผู้ดูแลระบบสูงสุด (Super Admin) ที่ต้องการกดเลือกจำนวนวันใช้งานมาตรฐานได้อย่างรวดเร็ว
- **Key Value**: คงความสะดวกในการกดเลือกจำนวนวันใช้งานด่วน พร้อมลดข้อความที่ไม่จำเป็นเพื่อให้แถวปุ่มลัดและวันหมดอายุดูสะอาดตาและกระชับขึ้น

## 2. User Experience & Visual Design

- **Key User Flows**:
  1. Super Admin เปิดหน้าจัดการผู้ใช้งานและสถานประกอบการ
  2. ในการ์ดแต่ละสถานประกอบการ ส่วนล่างของกล่องกำหนดวันใช้งานจะแสดงปุ่ม `30 วัน`, `90 วัน`, `180 วัน`, `365 วัน` ทางด้านซ้าย (ไม่มีคำว่า `"ตั้งค่าด่วน:"`) และตัวเลือก `วันหมดอายุ` ทางด้านขวา
  3. เมื่อคลิกปุ่มจำนวนวัน ระบบจะอัปเดตวันใช้งานและวันคงเหลือของสถานประกอบการนั้นทันที
- **Visual Identity & Theme**:
  - คงรูปแบบปุ่มลัดขนาดกะทัดรัด (`text-[11px]`, ขอบโค้ง `rounded`, สีพื้นหลังขาว และเปลี่ยนเป็นสีน้ำเงิน `bg-blue-600 text-white` เมื่อตรงกับจำนวนวันปัจจุบัน)
  - จัดวางในแถวเดียวกันกับตัวเลือกวันหมดอายุด้วย `flex flex-wrap items-center justify-between gap-1.5`

## 3. Key Product Decisions & Trade-Offs

- **Decision 1**: ลบเฉพาะ `<span>ตั้งค่าด่วน:</span>` และคงชุดปุ่ม `[30, 90, 180, 365]` ไว้
  - *Chosen Approach*: แสดงเฉพาะปุ่มตัวเลขจำนวนวัน (`30 วัน`, `90 วัน`, `180 วัน`, `365 วัน`) ชิดขอบซ้ายของแถวด้านล่าง
  - *Why*: ตัวปุ่มมีข้อความระบุหน่วย `"วัน"` ชัดเจนอยู่แล้ว การเอาคำว่า `"ตั้งค่าด่วน:"` ออกช่วยเพิ่มพื้นที่แนวนอนโดยไม่เสียฟังก์ชันการทำงาน

## 4. Technical Architecture & Data Strategy

```
┌──────────────────────────────────────────────────────────┐
│ การ์ดสถานประกอบการ (Facility Quota & Usage Card)         │
│  └─ กล่องกำหนดวันใช้งานและวันคงเหลือ (Unified Usage Box) │
│      ├─ แถวบน: ช่องกรอกกำหนดวันใช้งาน | วันคงเหลือ       │
│      └─ แถวล่าง (เฉพาะ Super Admin):                     │
│          ├─ ซ้าย: [30 วัน] [90 วัน] [180 วัน] [365 วัน]  │
│          │        (ลบ <span>ตั้งค่าด่วน:</span> ออก)     │
│          └─ ขวา: วันหมดอายุ [Date Input]                 │
└──────────────────────────────────────────────────────────┘
```

- **Interactive Component & State Mapping**:
  - ปุ่มแต่ละปุ่มเรียกใช้งาน `handleSaveFacilityUsageDays(fac, presetDays)` เพื่อบันทึกค่าวันใช้งานและคำนวณวันหมดอายุใหม่พร้อมแสดงสถานะบันทึกสำเร็จ
