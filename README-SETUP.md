# ระบบบริหารจัดการเครื่องมือแพทย์ (Medical Equipment Management System)

## วิธีการติดตั้งและรันในเครื่อง (Local Setup)

1. ตรวจสอบว่าได้ติดตั้ง Node.js (เวอร์ชัน 20 หรือสูงกว่า) เรียบร้อยแล้ว
2. แตกไฟล์ ZIP นี้ลงในโฟลเดอร์ที่ต้องการ
3. เปิด Terminal / Command Prompt ในโฟลเดอร์ แล้วสั่งคำสั่ง:
   ```bash
   npm install
   npm run dev
   ```
4. เปิดเว็บเบราว์เซอร์ไปที่: http://localhost:3000
